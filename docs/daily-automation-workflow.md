# TechMind Central — Daily Automation Workflow

## Schedule
Runs every day at 10:00 IST with a flexible one-hour execution window.

## Outputs
- 1 Hindi YouTube video (16:9)
- 1 English YouTube video (16:9)
- 1 Hindi YouTube-related Reel (9:16)
- 1 English YouTube-related Reel (9:16)
- 1 Hindi discovery/viral-test Reel (9:16)
- 1 English discovery/viral-test Reel (9:16)
- Thumbnails/covers, metadata and publishing windows

## Execution
1. Research current tech/AI/computer trends and available performance data.
2. Choose topics and angles autonomously for Indian + international audiences.
3. Write independent Hindi and English scripts; do not blindly translate.
4. Prepare voice direction using the user's voice/reference only when a connected provider supports it.
5. Generate video with Muse/Meta when available; use Runway/another connected provider as fallback.
6. Add permitted music/SFX with voice ducking and run quality checks.
7. Generate related and discovery Reels in 9:16.
8. Archive verified artifacts in Google Drive.
9. Send Telegram notifications for long-form assets and Reel files when supported; otherwise send Drive links.
10. Produce publish-ready YouTube/Instagram metadata. Keep publishing human-controlled unless a verified publisher is configured.
11. Record the daily creator log.
12. Pull available analytics and use the results to shape the next cycle.

## Quality gates
- Never claim a file exists without verified generation/export.
- Never claim Drive or Telegram delivery without verified success.
- Never commit API keys, tokens, cookies, private data or voice samples.
- Use only licensed/royalty-free/permitted music.
- Keep discovery experiments separate from YouTube-related Reels.
- Do not promise virality.
